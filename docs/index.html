轻笺是一款面向开发者与日常文本处理的轻量级 Windows 编辑器。 应用本体 < 1 MB，启动即用，离线也能跑满全部核心能力。

安装版约 125 MB（主要为 Electron 运行时）· 提供安装版与便携版

核心能力

覆盖日常写作、代码开发与文件管理，全部本地运行，无需登录、不上传数据。

✍️

编辑器核心

  • 多标签页编辑，支持拖拽排序
  • CodeMirror 6 语法高亮、行号、代码折叠、括号匹配
  • 20+ 语言：JS/TS、JSON、HTML、Python、Java、Go、SQL、Markdown…
  • 大文件分级：5–100 MB 关高亮保流畅，>100 MB 只读兜底
  • 查找/替换（正则）、跳转行、全局搜索
📂

文件与会话

  • 打开 / 保存 / 另存为 / 拖拽打开
  • 最近文件列表
  • 会话恢复：未保存的临时内容不丢失
  • 外部修改监听与提示
  • 自动保存（默认 3 秒防抖）
🧩

扩展视图

  • 侧边栏：文件目录树、大纲、代码片段
  • 电子表格：公式、跨表引用、20+ 函数、CSV/Excel 导入导出
  • 思维导图：文本一键转脑图
  • VCS 文件浏览器：连接 GitHub / Gitee / GitLab 远程浏览
⚙️

系统与更新

  • 无边框窗口 + 系统托盘，关闭不退出
  • 浅色 / 深色主题，首次默认浅色
  • 内置自动更新：下载完成原地升级
  • 保持你的安装路径与历史配置不变
  • 偏好设置：字体、字号、换行、缩进
