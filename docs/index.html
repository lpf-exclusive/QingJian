核心能力

覆盖 Markdown 写作、代码开发与文件管理，数据留在本机、无需登录；AI 助手按需自备密钥联网使用。

✍️

编辑器核心

  • 多标签页编辑，支持拖拽排序
  • CodeMirror 6 语法高亮、行号、代码折叠、括号匹配
  • 10 类语言高亮扩展：JS/TS、JSON、HTML、CSS、Python、Markdown、SQL、YAML、Shell…
  • 大文件分级：>50 MB 关高亮保流畅，>150 MB 只读兜底
  • 查找/替换（正则）、跳转行、全局搜索
📂

文件与会话

  • 打开 / 保存 / 另存为 / 拖拽打开
  • 最近文件列表
  • 会话恢复：未保存的临时内容不丢失
  • 外部修改监听与提示
  • 自动保存（默认 3 秒防抖）
🧩

扩展视图

  • 侧边栏：打开的文件、大纲视图、代码片段
  • 电子表格：公式、跨表引用、20+ 内置函数，Excel 导入导出；CSV 按普通文本打开
  • 思维导图：Markdown 标题大纲转 SVG 脑图，点节点可跳到对应行
  • VCS 文件浏览器：连接 GitHub / Gitee / GitLab 远程浏览
⚙️

系统与更新

  • 无边框窗口 + 系统托盘，关闭不退出
  • 浅色 / 深色主题，首次默认浅色
  • 内置自动更新：下载完成原地升级
  • 保持你的安装路径与历史配置不变
  • 偏好设置：字体、字号、换行、缩进
MD

Markdown 写作与导出

  • 分屏预览 / 仅预览 / 脑图模式，大纲导航按标题生成并跳转
  • 专注模式（Zen，Esc 退出）、字数统计与写作目标、命令面板快捷命令
  • 数学公式渲染（KaTeX）：行内 $...$、块级 $$...$$
  • 导出 Markdown、HTML、PDF、Word（.docx）；本地加密文件 + 恢复密钥
  • 侧边待办面板：自动收集任务项，勾选写回文档
AI

AI 助手

  • 右侧对话栏：Ctrl+Shift+A 唤出（启动时默认关闭），流式输出、多轮对话
  • BYOK：填入一个 API Key 即用；内置 20 个策展模型
  • 10 个内联动作：润色 / 续写 / 缩写 / 扩写 / 翻译 / 解释 / 正式 / 口语 / 活泼语气
  • 支持视觉的模型可附加图片；自定义系统提示词（设置 → AI 助手）
  • API Key 由操作系统凭据库保存，明文不落盘

下载

当前版本 最新版 · 支持 Windows / Linux

Windows 安装版 推荐

双击 QingJian_*_x64-setup.exe 按向导安装，开始菜单与桌面生成快捷方式。

下载 Windows 版

Linux 版 deb

适用于 Ubuntu / Debian 等（需系统 WebKit2GTK 4.1）。下载 .deb 后执行 sudo apt install ./QingJian_*_amd64.deb 即可。

下载 Linux 版

所有安装包托管于 GitHub Releases： lpf-exclusive/QingJian。 可在应用内「检查更新」获取新版本；若网络受限无法连接更新源，直接在上方下载安装包手动升级即可。
