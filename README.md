# 轻笺 (QingJian)

一款基于 Electron + CodeMirror 6 的轻量级 Windows 文本/代码编辑器，追求「秒开、不臃肿、可离线使用」。

🌐 官方主页：[https://lpf-exclusive.github.io/QingJian/](https://lpf-exclusive.github.io/QingJian/)

---

## 简介

轻笺是一款面向开发者和日常文本处理用户的轻量编辑器，采用现代 Web 技术栈实现。当前版本已实现多标签编辑、语法高亮、打开的文件面板、搜索替换、代码片段、电子表格预览、版本控制（VCS）浏览、思维导图、自动更新等能力。

- **安装包体积**：约 105 MB（主要由 Electron 运行时决定，应用本体 < 1 MB）
- **运行平台**：Windows（提供安装版与便携版）
- **当前版本**：v1.3.28（GitHub Release 已发布）

## 功能特性

### 编辑器核心
- 多标签页编辑，支持拖拽排序
- 基于 CodeMirror 6 的语法高亮、行号、代码折叠、括号匹配
- 多语言支持：JavaScript/TypeScript、JSON、HTML、CSS、Python、Java、C/C++、Go、Rust、SQL、Shell、Markdown、XML、YAML 等
- 大文件分级策略：5–100 MB 可编辑但关闭语法高亮保证流畅；>100 MB 硬只读兜底
- 查找/替换（支持正则）、跳转行、全局搜索
- 主题切换：浅色 / 深色 / 跟随系统（首次安装默认浅色；在「设置 → 外观 → 主题」中调整）
- 字体、字号、自动换行、缩进等偏好设置

### 文件与会话
- 本地文件打开 / 保存 / 另存为 / 拖拽打开
- 最近文件列表
- 会话恢复（未保存的临时内容不会丢失）
- 文件外部修改监听与提示
- 自动保存（默认 3 秒防抖）

### 扩展视图
- 侧边栏：打开的文件、大纲视图、代码片段
- 电子表格：支持公式、跨表引用、20+ 函数、CSV/Excel 导入导出
- 思维导图：文本转脑图

### 远程仓库（VCS 浏览）
- 支持 GitHub / Gitee / GitLab，填入访问令牌即可连接
- 在编辑器内浏览远程仓库的目录与文件树，无需把整个仓库 clone 到本地
- 远程打开文件直接查看内容，适合快速翻阅开源项目、摘录远端代码片段
- 定位为轻量只读浏览；提交、合并等完整 Git 工作流仍在你惯用的工具中完成

### AI 助手
- 常驻右侧对话栏：选中文字即以选区为上下文提问，无选区则发送全文，支持流式输出与多轮对话
- BYOK 模式：填入一个 API Key 即用，核心编辑器零强制联网、不依赖云端账号
- 内置 15 个策展免费模型（deepseek / qwen / moonshot / glm 等）开箱即用；专业用户可配付费 Key 解锁更强模型
- 6 类内联动作：润色 / 续写 / 缩写 / 扩写 / 翻译 / 解释（含语气）；触发方式：选区浮层「✨ AI」按钮、右键菜单、Ctrl+Shift+A
- 结果一键复制、替换原文或插入光标处
- 明文 Key 经主进程转发、safeStorage 本地加密存储，对话数据不出本机

### 系统与更新
- 自定义无边框窗口 + 系统托盘
- 关闭窗口不退出，托盘常驻
- 内置自动更新：下载完成自动原地升级，保持你的安装路径不变

## 安装与使用

### 安装版（推荐）

前往 [Releases](https://github.com/lpf-exclusive/QingJian/releases) 下载最新的 `QingJian-Setup-<版本>.exe`，双击运行，按向导完成安装即可。

### 便携版

下载 Releases 中的便携版 `QingJian-Portable-<版本>.exe`，双击即可运行，不写注册表，适合放在 U 盘或移动硬盘中使用。

### 首次启动

首次安装默认使用 **浅色主题**；可在「设置 → 外观 → 主题」中切换为深色，或选择「跟随系统」自动适配。

## 自动更新说明

轻笺内置自动更新机制，**全程对用户无感、无需手动干预**：

1. 启动后会在后台静默检查是否有新版本。
2. 发现新版本时通过托盘或菜单提示，点击「检查更新」即可下载安装包。
3. 下载完成后弹出确认框，确认即退出并启动安装包。
4. 安装包自动原地升级，保持你的安装路径不变，历史偏好与配置均保留。

如需手动检查，可在托盘菜单或主菜单「帮助 → 检查更新」中触发。

## 技术栈

- **Electron**：主进程、窗口管理、系统托盘、自动更新、本地服务
- **CodeMirror 6**：编辑器核心、语法高亮、搜索替换
- **NSIS**：Windows 安装包与卸载程序
- **electron-updater**：自动更新
